# Trading Portfolio Bot

Automated portfolio tracker for TQQQ and AGG holdings. Runs on a cron schedule, fetches live prices, calculates performance metrics, saves results to a local SQLite database, and sends a summary report via Telegram.

## How It Works

1. `run_trading.sh` is triggered by cron, loads credentials from `.env`, and runs `run_and_save.py`
2. `run_and_save.py` fetches 1-year price history via `yfinance`, computes portfolio metrics, saves a row to `trading.db`, and sends a Telegram message

## Project Structure

```
trading/
├── run_trading.sh        # Entry point (called by cron)
├── run_and_save.py       # Core analysis and reporting script
├── db.py                 # SQLite init and insert helpers
├── setup_portfolio.py    # Interactive setup to generate portfolio.json
├── portfolio.json        # Your holdings (shares + buy prices)
├── crontab.txt           # Cron schedule reference
├── .env                  # Credentials — not committed (see .env.example)
├── .env.example          # Credentials template
└── cron_log.log          # Runtime log (generated by cron, not committed)
```

## Setup

### 1. Clone and enter the repo

```bash
git clone https://github.com/HatemHaddad/trading.git
cd trading
```

### 2. Create and activate a virtual environment

```bash
python3 -m venv venv
source venv/bin/activate
pip install pandas numpy yfinance requests
```

### 3. Configure credentials

```bash
cp .env.example .env
```

Edit `.env` and fill in your Telegram bot token and chat ID:

```bash
export TELEGRAM_TOKEN="your_telegram_bot_token"
export TELEGRAM_CHAT_ID="your_telegram_chat_id"
```

### 4. Set up your portfolio

```bash
python3 setup_portfolio.py
```

This creates `portfolio.json` with your TQQQ and AGG positions.

### 5. Install the cron schedule

```bash
crontab -e
```

Paste the contents of `crontab.txt` (adjust paths if your project is not at `~/trading`).

## Cron Schedule

| Time | Days | Description |
|------|------|-------------|
| 5:30 PM | Mon–Fri | Runs after US market close |
| 12:00 AM | Tue–Sat | Overnight run |

Logs are written to `~/trading/cron_log.log`.

## Database

Results are stored in `trading.db` (SQLite), table `runs`. Key columns:

| Column | Description |
|--------|-------------|
| `run_at` | Timestamp of the run |
| `price_tqqq` / `price_agg` | Live closing prices |
| `total_curr_val` | Total portfolio value |
| `total_return` | Overall return since purchase |
| `sharpe` | Annualised Sharpe ratio |
| `max_drawdown` | Maximum drawdown over 1 year |
| `quarter_action` | BUY / SELL / HOLD recommendation |
| `shares_to_trade` | Number of TQQQ shares to act on |

## Environment Variables

| Variable | Description |
|----------|-------------|
| `TELEGRAM_TOKEN` | Telegram bot API token |
| `TELEGRAM_CHAT_ID` | Telegram chat or user ID to send reports to |
